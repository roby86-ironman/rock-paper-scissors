# Rock, Paper, Scissors vs. the Evil AI

## About the Game

A JavaScript Rock, Paper, Scissors game where the player competes against the Evil AI. The first to win three points wins the game.

## How to Play

1. Open `index.html` in a web browser.
2. When prompted, enter `Rock`, `Paper`, or `Scissors`.
3. You may use uppercase or lowercase letters and include extra spaces.
4. If your input is invalid or empty, an error message will appear and you will be asked to try again.
5. The game displays each round's result and the current score in the browser console.
6. The first player to reach three points wins. Draws do not award points.
7. To stop playing, cancel the input prompt.

## How to Open the Browser Console

In Google Chrome on Windows:

1. Open the game in Chrome.
2. Press `Ctrl + Shift + J` to open the Console.
3. View the round results, scores, and game messages in the Console.

You can also right-click the page, select **Inspect**, and open the **Console** tab.

## Technologies
